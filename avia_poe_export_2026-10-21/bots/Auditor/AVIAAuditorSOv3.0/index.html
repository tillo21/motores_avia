ℹ️ About AVIAAuditorSO v3.0

This is a demonstration prototype of an affective web accessibility auditor developed as part of academic research on human-centered accessibility tools.

🎯 Key Features:

  • Affective Engine: Real-time frustration detection through behavioral signals (typing speed, mouse movement, dwell time, repeated actions, pauses)
  • Proactive Interventions: Context-aware supportive messages when frustration is detected
  • Offline Explanations: 20+ built-in WCAG templates (no LLM required, privacy-first)
  • Voice Input: Hands-free interaction via Web Speech API
  • Full Accessibility: WCAG AAA compliant interface (screen reader optimized, keyboard navigable, high contrast)
  • Open Source: Download the complete source code below
