🎯 Procesos Disponibles

  • 🔺 UPSCALE - Mejora la resolución del video (2x, 4x, 8x)
  • 🎬 INTERPOLACION - Aumenta FPS (24→60, 30→120, etc.)
  • ✂️ AUTO_EDICION - Edición automática inteligente
  • 🎭 ELIMINACION_FONDO - Elimina fondo del video
  • 📹 ESTABILIZACION - Estabiliza video con IA
  • 🖼️ THUMBNAILS - Genera thumbnails optimizados
  • ©️ COPYRIGHT_CHECK - Verifica copyright de audio/video
  • 📦 COMPRESION - Comprime video inteligentemente
  • ⚡ PIPELINE_COMPLETO - Pipeline completo automático

💻 Ejemplo de Uso (Python)

import requests

query = """
mutation {
  quickUpscale(videoInput: "/videos/input.mp4", calidad: "4k") {
    id
    estado
    progreso
  }
}
"""

response = requests.post(
    'http://localhost:8000/graphql',
    json={'query': query}
)

print(response.json())
