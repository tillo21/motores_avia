Arquitectura Híbrida para Detección Emocional en Tiempo Real

Septiembre 2026 Proof of Concept Validado TensorFlow.js

AVIA Senior Research Team

🎯 El Problema

  • Seniors necesitan monitoreo emocional continuo para bienestar mental
  • Sistemas actuales: Lentos (300ms+), requieren cloud, poca privacidad
  • Español infrarepresentado: 90% de modelos optimizados solo para inglés
  • AVIA necesita: Análisis en tiempo real (<200ms) offline para 8 emociones

💡 Nuestra Solución: Sistema Híbrido

INPUT: "Estoy muy nervioso pero también emocionado" │ ├─► CAPA 1: Diccionario (8ms) │ └─► nervioso → miedo (0.8 + 0.3) = 1.0 │ └─► emocionado → alegría (0.85) │ ├─► CAPA 2: Machine Learning (35ms) │ └─► Análisis contextual con BiLSTM │ └─► Detección de emociones mixtas │ └─► FUSIÓN: 40% Dict + 60% ML └─► OUTPUT (47ms total): • Miedo: 92% • Alegría: 78%
