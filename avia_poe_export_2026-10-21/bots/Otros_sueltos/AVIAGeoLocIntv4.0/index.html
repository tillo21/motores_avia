    Ayuda y Documentación

    🌍 ¿Qué es GeoLocalización Inteligente?

    Una herramienta educativa y de privacidad que te permite analizar metadatos EXIF, coordenadas GPS y realizar análisis forense de imágenes. Todo el procesamiento ocurre en tu navegador, sin enviar datos a servidores externos.

    🔒 Privacidad y Seguridad

    • 100% Local: Ninguna imagen sale de tu dispositivo
    • Sin Tracking: No usamos cookies, analytics ni trackers
    • Código Abierto: Puedes revisar todo el código
    • Educación Digital: Aprende sobre metadatos y privacidad

    🚀 Cómo usar la aplicación

    1. Carga una imagen: Arrastra o selecciona una foto
    2. Revisa metadatos EXIF: Verifica coordenadas GPS, cámara, fecha
    3. Análisis con IA: Si no hay GPS, la IA puede sugerir ubicación
    4. Análisis Forense: Detecta manipulaciones y ediciones
    5. Exporta datos: Guarda el análisis en JSON

    ⚠️ Educación en Privacidad

    ¿Sabías que tus fotos pueden revelar tu ubicación?

    • Las fotos de móviles incluyen coordenadas GPS por defecto
    • Los metadatos EXIF revelan marca/modelo del dispositivo
    • Las fechas pueden exponer tus rutinas y horarios
    • Antes de compartir fotos online, elimina los metadatos sensibles

    🏗️ Tecnologías Utilizadas

    • exifr: Extracción avanzada de metadatos EXIF
    • Leaflet.js: Mapas interactivos sin API key
    • Canvas API: Análisis forense de imágenes
    • IndexedDB: Almacenamiento local seguro
    • Web Crypto API: Cifrado de datos sensibles
