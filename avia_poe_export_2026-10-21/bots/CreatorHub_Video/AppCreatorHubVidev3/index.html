Regla Universal AVIA

1️⃣
AutoCorrector (Pre-envío): Antes de cada llamada, valida el prompt. Si excede ~450 chars o contiene patrones que provocan respuestas largas, lo reduce automáticamente cortando por oración completa.
2️⃣
Persist (Snapshot): Antes de cada envío, guarda un snapshot del estado completo. Si ocurre un error, puede restaurar al estado anterior sin perder datos.
3️⃣
Siesta (Retry inteligente): Si detecta "Output token limit reached", espera 2s/5s/10s (backoff exponencial), reduce el prompt un 30% adicional, y reintenta hasta 3 veces.
4️⃣
Consenso (Post-respuesta): Si la respuesta del bot llega con error de token limit, el handler detecta el patrón, reduce el prompt un 40%, y reintenta automáticamente con un delay de 3s.
5️⃣
ErrorGuard (Runtime): Intercepta errores de sintaxis en tiempo real (SyntaxError, Unexpected token '...', ?., =>). Clasifica por 8 reglas (spread, optional chaining, nullish coalescing, template literals, arrow functions, destructuring, const/let, async/await) y notifica con fix sugerido. Incluye utilidades safe() y safeCall() para acceso seguro a propiedades.
