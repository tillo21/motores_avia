🚀 Bienvenido a AVIA Protocol v4.0

Primera implementación de AVIA Sandbox Guardian - Regla Universal #1 del ecosistema AVIAAgenOS.

✨ ¿Qué hace Sandbox Guardian?

  • 🔍 Detección Proactiva: Analiza el entorno antes de ejecutar código
  • 🔄 Auto-Corrección: Selecciona automáticamente la mejor estrategia de storage
  • 💾 Multi-Estrategia: localStorage → IndexedDB → sessionStorage → Memoria
  • 🚨 Notificación Inteligente: Avisa al usuario de limitaciones específicas
  • 📊 Diagnóstico Completo: Visualiza el estado de todas las tecnologías

📚 Documentación Técnica

🎯 ¿Por qué era necesario Sandbox Guardian?

El error original se debía a una contradicción arquitectural fundamental:

❌
El Problema: El código prometía "persistencia" con localStorage, pero se ejecutaba en un iframe sandbox que bloquea localStorage por diseño de seguridad.

¿Por qué no se previó?

  1. Falta de detección proactiva: No había código que verificara el entorno antes de ejecutar.
  2. Asunción incorrecta: Se asumió que localStorage siempre estaría disponible.
  3. Sin estrategias alternativas: No había fallback para entornos restrictivos.
  4. Documentación insuficiente: Solo se mencionaba "puede no funcionar" sin solución.

La Solución: AVIA Sandbox Guardian

// 1. DETECCIÓN PROACTIVA (se ejecuta PRIMERO) AVIASandboxGuardian.detectEnvironment(); // 2. AUTO-CORRECCIÓN (selecciona mejor estrategia) if (hasLocalStorage) → usar localStorage else if (hasIndexedDB) → usar IndexedDB else if (hasSessionStorage) → usar sessionStorage else → usar memoria RAM (con advertencia) // 3. ABSTRACCIÓN UNIVERSAL UniversalStorage.save(key, value); // ✅ Funciona en CUALQUIER entorno // 4. NOTIFICACIÓN AL USUARIO if (limitaciones) → mostrar alerta con solución

🔧 Integración como Regla Universal AVIAAgenOS

Este patrón se convierte en REGLA UNIVERSAL #1 de todo código AVIA:

📜
REGLA UNIVERSAL #1: Detección Proactiva de Entorno

Todo código AVIA debe:
1. ✅ Detectar el entorno ANTES de ejecutar lógica crítica
2. ✅ Proporcionar múltiples estrategias de fallback
3. ✅ Notificar limitaciones al usuario con soluciones
4. ✅ Usar abstracciones que funcionen en cualquier contexto
5. ✅ Nunca asumir disponibilidad de APIs del navegador

📊 Estrategias de Storage (en orden de prioridad)

Estrategia Persistencia Capacidad Sandbox-Safe
localStorage ✅ Permanente ~5-10 MB ❌ Bloqueado en sandbox
IndexedDB ✅ Permanente ~50+ MB ⚠️ Depende de flags
sessionStorage ⚠️ Solo sesión ~5 MB ⚠️ Depende de flags
Memoria RAM ❌ Se pierde al recargar Ilimitada ✅ Siempre funciona

💡 Cómo usar en tus proyectos

// ✅ CORRECTO: Usar UniversalStorage UniversalStorage.save('miDato', { foo: 'bar' }); var dato = UniversalStorage.load('miDato'); // ❌ INCORRECTO: Asumir localStorage localStorage.setItem('miDato', JSON.stringify({ foo: 'bar' })); // ^ Esto fallará en sandbox // ✅ CORRECTO: Verificar estrategia if (AVIASandboxGuardian.storageStrategy === 'localStorage') { console.log('Persistencia completa disponible'); } else { console.warn('Usando fallback:', AVIASandboxGuardian.storageStrategy); }
