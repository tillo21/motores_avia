🔐 Universal Auth Module

Purpose: Gestionar autenticación en entornos con almacenamiento restringido

Estrategias de Almacenamiento (Prioridad):

StrategyPersistenceLimitations
localStorage Permanente (hasta borrar datos) Puede estar bloqueado en sandbox
sessionStorage Mientras la pestaña esté abierta Se pierde al cerrar pestaña
memory Mientras la página esté cargada Se pierde al recargar página

Uso:

// Login UniversalAuth.login('username', 'password', { permissions: ['read', 'write', 'admin'], metadata: { role: 'developer' } }) .then(result => { console.log('Logged in:', result.user); console.log('Token:', result.token); }) .catch(error => { console.error('Login failed:', error.message); }); // Logout UniversalAuth.logout(); // Check authentication if (UniversalAuth.isAuthenticated()) { var user = UniversalAuth.getCurrentUser(); console.log('Current user:', user.username); } // Check permission if (UniversalAuth.hasPermission('admin')) { console.log('User has admin permission'); } // Get stats var stats = UniversalAuth.getStats(); console.log('Auth strategy:', stats.strategy); console.log('Total logins:', stats.logins);

Características:

  • ✅ Multi-estrategia automática: Selecciona localStorage → sessionStorage → memory
  • ✅ Persistencia de sesión: Restaura sesión automáticamente si está disponible
  • ✅ Sistema de permisos: Gestión granular de permisos por usuario
  • ✅ Log completo: Registro de todas las acciones de autenticación
  • ✅ Tokens seguros: Generación de tokens únicos por sesión
  • ⚠️ Advertencias contextuales: Notifica cuando la sesión no persistirá

🔌 Universal WebSocket Module

Purpose: Comunicación en tiempo real con fallback automático a polling

Estrategias (con Fallback Automático):

StrategyLatencyCompatibility
websocket ~10ms (bidireccional) Puede fallar en sandbox estricto
polling ~3000ms (configurable) Funciona en cualquier entorno
⚡
Fallback Automático: Si WebSocket falla al conectar (común en sandbox), el sistema automáticamente cambia a polling sin intervención del desarrollador.

Uso:

// Inicializar UniversalWebSocket.init(); // Conectar UniversalWebSocket.connect('wss://api.example.com/ws') .then(result => { console.log('Connected via:', result.strategy); // result.strategy puede ser 'websocket' o 'polling' }); // Registrar handlers UniversalWebSocket.on('connected', data => { console.log('Connected!', data.strategy); }); UniversalWebSocket.on('message', message => { console.log('Message received:', message); }); UniversalWebSocket.on('disconnected', () => { console.log('Disconnected'); }); // Enviar mensaje UniversalWebSocket.send({ type: 'chat', data: { message: 'Hello!' } }); // Desconectar UniversalWebSocket.disconnect();

Ejemplo: RealTimeAgent

var RealTimeAgent = { name: 'RealTimeAgent', environmentDetected: false, detectEnvironment: function() { this.environment = AVIAAgenOS.environment; this.environmentDetected = true; }, init: function() { this.detectEnvironment(); // Configurar handlers UniversalWebSocket.on('connected', data => { console.log('Agent connected via', data.strategy); }); UniversalWebSocket.on('message', message => { this.handleMessage(message); }); AVIAAgenOS.registerAgent(this); }, connect: function() { return UniversalWebSocket.connect('wss://api.example.com/ws'); }, handleMessage: function(message) { console.log('Processing:', message); // Lógica del agente... } }; RealTimeAgent.init();

📊 Visual Dashboard Structure

Purpose: Monitoreo visual en tiempo real del estado del sistema

Componentes del Dashboard:

1. System Stats (Grid Superior)
  • Número de agentes activos
  • Estado de autenticación (🔓 / 🔒)
  • Estado de conexión WebSocket (🟢 / 🔴)
2. Agent Cards

Cada agente registrado tiene su propia card con:

  • Header: Nombre del agente + badge de estado (Active/Inactive)
  • Metadata: Versión + estado de conexión
  • Stats: Métricas específicas del agente (mensajes, eventos, etc.)
