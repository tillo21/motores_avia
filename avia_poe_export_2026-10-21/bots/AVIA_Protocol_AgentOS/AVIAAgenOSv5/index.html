📚 Documentation

🌐 Universal Fetch Module

Purpose: Ensure network requests never fail in restricted environments

Fetch Strategies (Priority Order):

StrategyDescriptionUse Case
fetch Standard Fetch API with CORS Normal browser environment
fetch-no-cors Fetch API in no-cors mode (response not readable) CORS blocked but fetch available
mock Mock responses (can be pre-registered) Fully restricted sandbox or testing

Usage Example:

// ✅ Universal Fetch - Works in ANY environment UniversalFetch.request('https://api.example.com/data', { method: 'GET', headers: { 'Content-Type': 'application/json' } }) .then(response => { console.log('Response:', response); if (response.mock) { console.warn('Using mock data'); } }) .catch(error => { console.error('Error:', error); }); // Register mock for testing/restricted environments UniversalFetch.registerMock( 'https://api.example.com/data', 'GET', { status: 'ok', data: [1, 2, 3] } );

🏥 Auto-Diagnostics Module

Purpose: Automatic system health monitoring with intelligent export in memory mode

Key Features:

  • Automatic Detection: Runs diagnostics on boot and periodically
  • Smart Recommendations: Generates actionable recommendations based on environment
  • Auto-Export: In memory mode, automatically exports logs every 60s to prevent data loss
  • Comprehensive Reports: System, storage, network, and performance metrics

Critical Feature: Auto-Export in Memory Mode

🔄
When storage strategy is "memory", Auto-Diagnostics automatically enables periodic export (every 60 seconds) to prevent data loss on page reload. This ensures critical logs are preserved even in the most restricted environments.
// Manual diagnostics run var report = AutoDiagnostics.run(); // Enable/disable auto-export AutoDiagnostics.enableAutoExport(); AutoDiagnostics.disableAutoExport(); // Manual export AutoDiagnostics.export(); // Get latest report var latest = AutoDiagnostics.getLatestReport();

🚀 Core Bootstrap Module

Purpose: Universal boot system ensuring all agents follow Universal Rule #1

Boot Sequence (4 Phases):

PhaseNameDescription
1 Environment Detection Proactive detection via Sandbox Guardian (CRITICAL)
2 Core Modules Init Initialize UniversalStorage, UniversalFetch, AutoDiagnostics
3 Auto-Diagnostics Run initial system diagnostics
4 Agent Registration Register and validate all agents

Agent Registration Validation:

// ✅ CORRECT: Agent with environment detection var MyAgent = { name: 'MyCustomAgent', version: '1.0.0', environmentDetected: false, init: function() { // MUST call environment detection first this.detectEnvironment(); // Then initialize console.log('MyAgent initialized'); // Register with core system AVIAAgenOS.registerAgent(this); }, detectEnvironment: function() { // Access global environment this.environment = AVIAAgenOS.environment; this.environmentDetected = true; console.log('MyAgent: Environment detected'); } }; // ❌ INCORRECT: Agent without detection var BadAgent = { name: 'BadAgent', init: function() { AVIAAgenOS.registerAgent(this); // Will throw error! } };

📜 Universal Rule #1 Integration

The Core Bootstrap ensures ALL agents follow the Universal Rule #1:

📜
UNIVERSAL RULE #1: Proactive Environment Detection

Every agent in AVIAAgenOS MUST:
1. ✅ Detect environment BEFORE executing critical logic
2. ✅ Use Universal modules (Storage, Fetch) for cross-environment compatibility
3. ✅ Register with AVIAAgenOS.registerAgent() after detection
4. ✅ Implement fallback strategies for restricted environments
5. ✅ Never assume availability of browser APIs
/** * TEMPLATE: Universal Agent * Copy this template for all new agents */ var UniversalAgentTemplate = { // Required metadata name: 'AgentName', version: '1.0.0', environmentDetected: false, // Required: Environment detection detectEnvironment: function() { this.environment = AVIAAgenOS.environment; this.environmentDetected = true; console.log('[' + this.name + '] Environment detected'); // Adapt behavior based on environment if (this.environment.storageStrategy === 'memory') { console.warn('[' + this.name + '] Memory mode - data will not persist'); } }, // Required: Initialization init: function() { console.log('[' + this.name + '] Initializing...'); // STEP 1: Detect environment (CRITICAL) this.detectEnvironment(); // STEP 2: Initialize agent logic this.setupAgent(); // STEP 3: Register with core system AVIAAgenOS.registerAgent(this); console.log('[' + this.name + '] Ready'); }, // Agent-specific logic setupAgent: function() { // Use Universal modules var savedData = UniversalStorage.load('agent-data', {}); // Your agent code here console.log('[' + this.name + '] Setup complete'); } }; // Initialize the agent UniversalAgentTemplate.init();
