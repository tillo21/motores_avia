GitHub rechazó un lote por detección de un secreto. Se sustituyó un valor incrustado en el campo «Clave API» de `bots/AVIA_Senior/AVIA-SeniorAdmin/index.html` por `TU_CLAVE_API_NO_INCLUIDA`. No se publica el ZIP original sin corregir. Los otros 1.856 archivos se conservan sin cambios; la integridad de todos los archivos de la copia publicada se verificó mediante sus identificadores Git.
